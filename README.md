# The Commonplace — creative blog and portfolio

A free, editable Jekyll starter for GitHub Pages. No paid themes or plugins.

## Publish it

1. Create a **public** GitHub repository named `the-commonplace` (or any name you prefer).
2. Upload all the contents of this folder (including `_layouts`, `_posts`, `assets`, `about` and `_config.yml`) to the repository root. GitHub's **Add file → Upload files** supports this, or use Git locally.
3. In `_config.yml` set `baseurl: "/the-commonplace"` if your repository is named `the-commonplace`. If your repository is named exactly `YOURUSERNAME.github.io`, leave `baseurl: ""`.
4. Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, and save.
5. Your project website address will be `https://YOURUSERNAME.github.io/the-commonplace/` (or `https://YOURUSERNAME.github.io/` for the special username repository).

## Edit it

- Rename the site by changing `title` in `_config.yml` and text in `_layouts/default.html`.
- Change homepage content in `index.html`.
- Edit the colours and layout in `assets/style.css`.
- Edit your biography in `about/index.md`.
- Create journal posts in `_posts/YYYY-MM-DD-post-title.md` with metadata matching the existing examples.
- Replace the placeholder `hello@example.com` in `_layouts/default.html` with your own contact email before publishing.
- Replace the sample articles and portfolio placeholders with your own work.

**Important:** GitHub Pages is public-facing. Don't upload private documents or secrets. Posts are published by commits, rather than through a WordPress-style editor.
